Every number the paper may use, with the run that produced it and the file that holds it. Run folders are under
`experiments/c01_journal_graph/runs/`; the lab notebook with full context is `experiments/c01_journal_graph/RESULTS_LOG.md`

gitignored and regenerated by the command in each `run.json`; their sha256 values are in each `SHA256SUMS`.

**Working title:** *Can open citation data detect citation stacking? An audit against Clarivate's journal suppressions.*
**Framing:** an audit of journal-level manipulation detection on fully open data (OpenCitations, Jan 2024, all fields),
against Clarivate's published suppression lists and numbers (JCR data years 2015–2023). Journal-level only;
"anomalous pattern", never "misconduct"; no editor or author names.
